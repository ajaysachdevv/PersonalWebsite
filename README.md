# ajaysachdev.com

Personal site of Ajay Sachdev: a finance and operations manager who builds production software. The homepage is a scroll-film in four chapters with playable simulations of real systems he runs, presented as an audited statement of work.

## Stack

Static HTML, CSS and JavaScript. No framework, no build step. GSAP + ScrollTrigger and Lenis via CDN, with a vendored fallback if the CDN is unavailable. Deployed on GitHub Pages.

## Run locally

Open `index.html` in a browser, or:

```
python -m http.server 8765
```

Press T anywhere on the site for the terminal.
