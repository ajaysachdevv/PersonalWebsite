# ajaysachdev.com

Personal site of Ajay Sachdev: a finance and operations manager who builds production software. The home page is the story (where he started, the day job, doors to the projects and the About page). /projects/ lists every project, and each case page has one moment you can play with.

## Stack

Static HTML, CSS and JavaScript. No framework, no build step. GSAP + ScrollTrigger and Lenis, self-hosted in `vendor/`, fonts self-hosted. Deployed on GitHub Pages.

## Run locally

Open `index.html` in a browser, or:

```
python -m http.server 8765
```

On the home page, press T or tap the owl for the terminal.
